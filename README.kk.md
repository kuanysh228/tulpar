# Tulpar (Тұлпар)

[English](README.md) · [Русский](README.ru.md) · **Қазақша**

![License: MIT](https://img.shields.io/badge/license-MIT-green) ![Language: Tulpar](https://img.shields.io/badge/language-Tulpar_(.tlp)-e8b923) ![Platform: Linux x86-64](https://img.shields.io/badge/platform-linux--x86--64-blue) ![Written in Rust](https://img.shields.io/badge/compiler-Rust-orange)

Қазақ синтаксисі бар, Python сияқты қарапайым, бірақ **нативті машиналық кодқа компиляцияланатын** бағдарламалау тілі.
Файл кеңейтімі — `.tlp`. Компилятор мен рантайм **нөлден** жазылған (LLVM жоқ, C компиляторы жоқ, libc жоқ).

* статикалық типтер, бірақ **типтерді шығару** арқылы жазылады (`x = 5` — `бүтін`)
* **GC** (қоқыс жинаушы) автоматты қосылған, сонымен қатар **қолмен жад басқару** (`бөл` / `босат`) мүмкіндігі бар
* Python сияқты шегініс синтаксисі, кластар, мұралау, кортеждер, генераторлар, f-жолдар
* жылдам: төмендегі тесттерде CPython-нан 17–140 есе жылдам; C `-O2` мен Rust-тан 1,0–2,4 есе баяу
* қателер қазақ тілінде, сатылы көрсеткішпен

```python
анықта фиб(n: бүтін) -> бүтін:
    егер n < 2:
        қайтар n
    қайтар фиб(n - 1) + фиб(n - 2)

әр і ішінде аралық(10):
    жаз(f"фиб({і}) = {фиб(і)}")
```

## Орнату және іске қосу

Қажет: Linux x86-64, Rust (cargo), GNU binutils (`as`, `ld`).

```bash
cargo build --release          # компилятор + рантайм
./install.sh                   # (қалауыңызша) ~/.local/bin/tulpar
tests/run_tests.sh             # тесттер

tulpar run   файл.tlp          # компиляциялап іске қосу
tulpar build файл.tlp -o prog  # дербес орындалатын файл (libc-сіз, статикалық ELF)
tulpar asm   файл.tlp          # ассемблер кодын көру
tulpar check файл.tlp          # тек тексеру
```

Опциялар: `-O0` — регистр бөлгішсіз/оңтайландырусыз (түзету үшін), `--ir` — IR шығару.

| `әзірше` | `while` | | `глобал` | `global` |

### Типтер

| Tulpar | мағынасы |
|---|---|
| `бүтін` | 64-биттік таңбалы бүтін (асып кетсе айналады) |
| `нақты` | `float64` |
| `логика` | `рас` / `жалған` |
| `мәтін` | өзгермейтін UTF-8 жол; **индекс пен кесу таңбалар бойынша** (`ұзындық("Қазақстан") == 9`) |
| `байт` | 0..255 (қолмен жад үшін) |
| `тізім[T]`, `сөздік[K, V]`, `жиын[T]` | динамикалық массив, ретті хеш-кесте, жиын (кілт/элемент: `бүтін`/`мәтін`/`логика`/`байт`) |
| `(T1, T2, …)` | кортеж (бірнеше мән қайтару) |
| `Класс` | пайдаланушы кластары (сілтеме семантикасы) |
| `*T` | көрсеткіш (тек `қолмен:` блогында) |

Айнымалылар `x = 5` деп жазылады, типі бірінші меншіктеуден шығарылады. Бос контейнерге тип қою керек:
`x: тізім[бүтін] = []`. `бүтін` → `нақты` автоматты (араласқан арифметикада), кері бағытта `бүтін(x)` қолданыңыз.

### Функциялар

```python
анықта қосу(a: бүтін, b: бүтін = 10) -> бүтін:     # параметр типтері міндетті, қайтару типі шығарылады
    қайтар a + b

жаз(қосу(1), қосу(b=2, a=3))                      # атаулы аргументтер, әдепкі мәндер

анықта бөлу(a: бүтін, b: бүтін) -> (бүтін, бүтін):  # бірнеше мән
    қайтар a // b, a % b
q, r = бөлу(17, 5)
```

Рекурсивті функцияларға `-> тип` көрсету керек. Жоғарғы деңгейдегі айнымалыны функция ішінде өзгерту үшін `глобал x`.

### Функциялар мән ретінде, лямбда

```python
анықта екі_есе(x: бүтін) -> бүтін:
    қайтар x * 2

анықта қолдан(f: (бүтін) -> бүтін, x: бүтін) -> бүтін:    # функция типі: (параметрлер) -> қайтару
    қайтар f(f(x))

жаз(қолдан(екі_есе, 3), қолдан(лямбда x: x + 100, 1))     # 12 201
сөздер.сұрыпта(лямбда w: ұзындық(w))                       # кілт бойынша тұрақты сұрыптау
```

Лямбда типін контекстен алады (`f: (бүтін) -> бүтін = лямбда x: x + 1`) және сыртқы айнымалыларды ұстамайды (замыкание жоқ).

### Кластар және мұралау

```python
класс Жануар:
    аты: мәтін
    жас: бүтін = 1                       # өрістің әдепкі мәні

    анықта құру(өзі, аты: мәтін):        # конструктор (міндетті емес)
        өзі.аты = аты
    анықта дыбыс(өзі) -> мәтін:
        қайтар "..."

класс Ит(Жануар):
    анықта дыбыс(өзі) -> мәтін:           # виртуалды әдіс (қайта анықтау)
        қайтар "Әу!"

үй: тізім[Жануар] = [Ит("Ақбөрі"), Жануар("Х")]
әр ж ішінде үй:
    жаз(ж.аты, ж.дыбыс())
жаз(мысал(үй[0], Ит), түрлендір(үй[0], Ит).аты)    # isinstance және тексерілетін downcast
# Жануар.құру(өзі, аты) — ата-ана әдісін тікелей шақыру (super)
```

`құру` болмаса, конструктор өрістер ретімен аргумент алады: `Нүкте(1.0, 2.0)` немесе `Нүкте(y=2.0, x=1.0)`.
Жалғыз мұралау, `None` (`жоқ`) мәні кез келген класс/тізім/сөздік/мәтін/көрсеткішке беріледі.

### Жинақтар

```python
a = [3, 1, 2]
a.қос(5); a.сұрыпта(); жаз(a, a[-1], a[1:3], ұзындық(a))       # [1, 2, 3, 5] 5 [2, 3] 4
d = {"бір": 1}
d["екі"] = 2
әр кілт, мән ішінде d: жаз(кілт, мән)
жаз([x * x әр x ішінде аралық(10) егер x % 2 == 0])             # генератор
әр і, x ішінде нөмірле(a): жаз(і, x)                             # enumerate
жаз([1, 2] == [1, 2], (1, "а") == (1, "а"))                      # құрылымдық теңдік
```

| Тізім | | Мәтін | | Сөздік |
|---|---|---|---|---|
| `.қос(x)` `.ал()` | қосу / соңғысын алу | `.үлкен()` `.кіші()` | регистр (кирилл, қазақ әріптерімен) | `.жой(k)` |
| `.тазала()` `.кері()` `.сұрыпта()` | | `.тазарт()` | бос орындарды алу | `.ал(k, әдепкі)` |
| `.индекс(x)` `.өшір(i)` `.кірістір(i, x)` `.көшірме()` | | `.бөлу(с)` `.біріктір(тізім)` | split / join | `.кілттер()` `.мәндер()` |
| `қосынды(l)` `мин(l)` `макс(l)` | | `.тап(с)` `.ауыстыр(a, b)` | | |
| | | `.басталады(п)` `.аяқталады(п)` `.байт(i)` | | |

Жиын: `{1, 2, 3}`, `жиын[мәтін]()`, `жиын(тізім)`, `x ішінде s`, `.қос(x)`, `.жой(x)`, `.тізім()`, операторлар `|` `&` `-`.
Мәтін: `код("А")` (Unicode коды), `таңба(1179)`, `.сан_ма()`, `.әріп_ма()`, `.бөлу()` (бос орындар бойынша), `.саны(с)`.

f-жолдар: `f"{x}"` немесе `ф"{x}"`; пішімдеу: `{x:.2f}`, `{x:8}`, `{s:>10}`, `{s:<10}`, `{s:^10}`.

## Жадты басқару

**Әдепкі — автоматты (GC).** Мәтін, тізім, сөздік, кластар мен кортеждер GC үйіндісінде тұрады; ештеңе босату керек емес.
GC — консервативті *mark-sweep* (стек пен глобал айнымалылар түбір), өлшем кластарына бөлінген spans, ішкі көрсеткіштерді де таниды.
Көрсеткіші жоқ объектілер (мәтін, `тізім[бүтін]` т.б.) сканерленбейді.
`жина()` — GC-ді мәжбүрлеп іске қосу, `жад()` — үйінді өлшемі (байт).

**Қолмен басқару** `қолмен:` блогында ғана рұқсат етіледі:

```python
қолмен:
    p = бөл(бүтін, 1000)       # *бүтін, нөлденген, GC-ге жатпайды
    әр і ішінде аралық(1000):
        p[і] = і * і            # p[i] немесе *p
    жаз(p[10], *p)
    p2 = p + 5                  # көрсеткіш арифметикасы (элемент өлшемімен)
    босат(p)                    # міндетті түрде өзіңіз босатасыз
```

* `бөл(T, n)` — `n` элементті `*T` блогы; `T = байт` үшін 1 байт/элемент, қалғандары 8 байт
* қолмен блоктың ішінде GC-объектілерге сілтемелер (`бөл(мәтін, 4)`, `бөл(Класс, 4)`) **сақтауға болады** — GC оларды түбір деп қарайды
* қос босату / `бөл` арқылы алынбаған көрсеткішті босату — қателік беріп тоқтайды

## Желі (TCP, HTTP)

```python
сервер = тыңда_локал(8080)            # тек localhost тыңдау (тыңда(8080) — барлық интерфейс)
әзірше рас:
    клиент = қабылда(сервер)          # келесі қосылымды күту
    сұраныс = желі_оқы(клиент)        # бір рет оқу (64 КБ дейін), жабылса — ""
    дене = "Сәлем!"
    желі_жаз(клиент, f"HTTP/1.1 200 OK\r\nContent-Length: {дене.байт_саны()}\r\n\r\n{дене}")
    желі_жап(клиент)

с = қосыл("127.0.0.1", 8080)          # клиент; сәтсіз болса -1 (тек IPv4 және localhost, DNS жоқ)
```

Толық мысалдар: `examples/http_server.tlp`, `examples/http_client.tlp`. HTTPS/TLS және DNS әлі жоқ; бір ағын (сұраныстар кезекпен өңделеді).

## Көп файлды бағдарламалар

```python
импорт "утилиталар"        # утилиталар.tlp (жол импорттаушы файлға қатысты) бір рет қосылады
жаз(квадрат(12))
```

`импорт` файлды орнында ашады (include сияқты): атаулар ортақ, жоғарғы деңгей коды импорт орнында орындалады.

## Орындау уақытындағы қателер

Бағдарлама нақты хабарламамен және **шақырулар тізбегімен (файл, жол, функция)** `1` кодымен тоқтайды:
индекс шектен тыс, сөздікте кілт жоқ, нөлге бөлу, нөлдік көрсеткіш (`жоқ`), стек толып кетті (стек 1 ГБ виртуал),
`тексер` сәтсіз, `қате("…")`, бос тізімнен `ал`.

```
Шақырулар тізбегі (соңғысы төменде):
  "prog.tlp", 16-жол, <main>
  "prog.tlp", 13-жол, сыртқы
  "prog.tlp", 7-жол, тереңірек
Қате: нөлдік көрсеткішке (жоқ) қатынау
```

(Инлайнданған кішкентай функциялар трассада шақырушының атымен көрінуі мүмкін.)

```

  lexer.rs      шегініс бойынша токендер, f-жолдар, Unicode идентификаторлар
  parser.rs     рекурсивті төмендеу парсері -> ast.rs
  check.rs      типтерді тексеру/шығару, AST -> hir.rs (типтелген ағаш)
  lower.rs      HIR -> ir.rs (виртуал регистрлері бар үш адресті IR, негізгі блоктар)
  opt.rs        CFG жеңілдету, константтар, көшірмелер, mov біріктіру, DCE, test біріктіру
  regalloc.rs   сызықтық сканерлеу регистр бөлгіші (салмақтар, callee-saved/caller-saved)
  codegen.rs    x86-64 (Intel синтаксисі), System V ABI -> `as` + `ld`
runtime/src/    (no_std, libc жоқ; syscall-дар тікелей)

```

Объектілер: жолдар `[байт ұз.][таңба саны][байттар]`, тізімдер `[ұз.][сыйымдылық][деректер][жалаулар]`, кластар — өрістер 8 байттан
(иерархияда 0-ші сөз — класс ID, виртуалды шақыру `vtable[id]` арқылы). Барлық 8-байттық мәндер консервативті сканерленеді.

## Өнімділік

`bench/` (Linux x86-64, 8 ядро). Rust — `rustc -O`, C — `gcc -O2`, Python — CPython 3.14 (`bench/bench.py`). Бір іске қосудың уақыты:

| тест | Tulpar | Rust | C `-O2` | Python 3 |
|---|---|---|---|---|
| Коллатц, 3 млн сан | 0,59 с | 0,34 с | 0,47 с | 33 с |
| Эратосфен електі, 2·10⁷ | 0,13 с | 0,11 с | 0,10 с | 2,2 с |
| нақты сандар циклі, 10⁸ | 0,13 с | 0,12 с | 0,13 с | 18 с |
| `фиб(42)` | 1,55 с | 0,65 с | 0,39 с | 36 с |

Tulpar қарапайым циклдерде Rust/C-ге жақын, ал рекурсияда ~2,4 есе, тармақталуда ~1,7 есе баяу: рекурсияны ашу,
векторландыру, күрделі `cmov` таңдауы әлі жоқ. Оңтайландырулар: инлайндау, сызықтық сканерлеу
регистр бөлгіші, `cmov` түрлендіруі (if-conversion), константтарды бүктеу, көшірмелерді тарату, өлі кодты жою, цикл инверсиясы.

Дифференциалды фаззер (`python3 tools/fuzz.py 0 500`) кездейсоқ бағдарламаларды `-O0`, оңтайландырылған режимде және
Python эталонымен салыстырады.

## Шектеулер (қазір)

* Желі: тек TCP/IPv4, TLS және DNS жоқ, бір ағын; тек Linux x86-64; `as` және `ld` қажет (өз ассемблері/линкері әлі жоқ)
* `импорт` — include сияқты (атаулар кеңістігі жоқ); лямбда сыртқы айнымалыларды ұстамайды, жалпылама (generic) пайдаланушы функциялары, ерекше жағдайлар (`try`) жоқ
* Бүтін сан 64 бит (үлкен сандар жоқ, асып кетсе айналады)
* GC бір ағынды және консервативті (сирек жағдайда жалған сілтеме жадты біраз ұстап тұруы мүмкін)
* `мәтін` UTF-8, `байт(i)` — байт бойынша қолжетімділік; үлкен әріптер үшін тек ASCII, кирилл және қазақ әріптері
