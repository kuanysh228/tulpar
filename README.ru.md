# Tulpar (Тұлпар)

[English](README.md) · **Русский** · [Қазақша](README.kk.md)

![License: MIT](https://img.shields.io/badge/license-MIT-green) ![Language: Tulpar](https://img.shields.io/badge/language-Tulpar_(.tlp)-e8b923) ![Platform: Linux x86-64](https://img.shields.io/badge/platform-linux--x86--64-blue) ![Written in Rust](https://img.shields.io/badge/compiler-Rust-orange)

Язык программирования с **казахским синтаксисом**, простой как Python, но **компилируемый в нативный машинный код**.
Файлы имеют расширение `.tlp`. Компилятор и рантайм написаны **с нуля**: без LLVM, без C-компилятора, без libc.

* статические типы с **выводом типов** (`x = 5` — это `бүтін`, целое число)
* автоматический **сборщик мусора** и при этом **ручное управление памятью** (`бөл` / `босат`)
* отступы как в Python, классы, наследование, кортежи, генераторы списков, f-строки, лямбды, множества, импорт
* быстрый: в 17–140 раз быстрее CPython на приведённых ниже тестах, в 1,0–2,4 раза медленнее C `-O2` и Rust
* сообщения об ошибках на казахском с указанием строки; ошибки времени выполнения печатают стек вызовов с файлом и строкой

```python
анықта фиб(n: бүтін) -> бүтін:
    егер n < 2:
        қайтар n
    қайтар фиб(n - 1) + фиб(n - 2)

әр і ішінде аралық(10):
    жаз(f"фиб({і}) = {фиб(і)}")
```

## Установка и запуск

Нужно: Linux x86-64, Rust (cargo) чтобы один раз собрать компилятор, GNU binutils (`as`, `ld`).

```bash
cargo build --release          # компилятор + рантайм
./install.sh                   # по желанию: установка в ~/.local/bin/tulpar
tests/run_tests.sh             # тесты

tulpar run   файл.tlp          # скомпилировать и запустить
tulpar build файл.tlp -o prog  # самостоятельный исполняемый файл (статический ELF, без libc)
tulpar asm   файл.tlp          # показать сгенерированный ассемблер
tulpar check файл.tlp          # только проверка типов
```

Опции: `-O0` отключает оптимизации и аллокатор регистров (для отладки), `--ir` выводит IR.
После однократной сборки нужен только бинарник `tulpar`; `cargo` для компиляции `.tlp`-программ не используется.

### Типы

| Tulpar | значение |
|---|---|
| `бүтін` | 64-битное знаковое целое (при переполнении «заворачивается») |
| `нақты` | `float64` |
| `логика` | `рас` / `жалған` (истина / ложь) |
| `мәтін` | неизменяемая UTF-8 строка; **индексы и срезы считаются по символам** (`ұзындық("Қазақстан") == 9`) |
| `байт` | 0..255 (для ручной памяти) |
| `тізім[T]`, `сөздік[K, V]`, `жиын[T]` | динамический массив, упорядоченная хеш-таблица, множество (ключи/элементы: `бүтін`/`мәтін`/`логика`/`байт`) |
| `(T1, T2, …)` | кортеж (несколько возвращаемых значений) |
| `(T1) -> R` | значение-функция |
| `Класс` | пользовательские классы (ссылочная семантика) |
| `*T` | указатель (только внутри блока `қолмен:`) |

Переменные пишутся `x = 5`, тип выводится из первого присваивания. Пустым контейнерам нужен тип:
`x: тізім[бүтін] = []`. `бүтін` автоматически превращается в `нақты` в смешанной арифметике; в обратную сторону — `бүтін(x)`.

### Функции

```python
анықта қосу(a: бүтін, b: бүтін = 10) -> бүтін:     # типы параметров обязательны, тип результата выводится
    қайтар a + b

жаз(қосу(1), қосу(b=2, a=3))                      # именованные аргументы, значения по умолчанию

анықта бөлу(a: бүтін, b: бүтін) -> (бүтін, бүтін):  # несколько значений
    қайтар a // b, a % b
q, r = бөлу(17, 5)
```

Рекурсивным функциям, которые возвращают значение, нужно указывать `-> тип`. Чтобы изменить переменную верхнего уровня внутри функции, используйте `глобал x`.

### Функции как значения, лямбды

```python
анықта екі_есе(x: бүтін) -> бүтін:
    қайтар x * 2

анықта қолдан(f: (бүтін) -> бүтін, x: бүтін) -> бүтін:    # тип функции: (параметры) -> результат
    қайтар f(f(x))

жаз(қолдан(екі_есе, 3), қолдан(лямбда x: x + 100, 1))     # 12 201
сөздер.сұрыпта(лямбда w: ұзындық(w))                       # устойчивая сортировка по ключу
```

Тип лямбды берётся из контекста (`f: (бүтін) -> бүтін = лямбда x: x + 1`); внешние переменные лямбда не захватывает (замыканий нет).

### Классы и наследование

```python
класс Жануар:
    аты: мәтін
    жас: бүтін = 1                       # значение поля по умолчанию

    анықта құру(өзі, аты: мәтін):        # конструктор (необязателен)
        өзі.аты = аты
    анықта дыбыс(өзі) -> мәтін:
        қайтар "..."

класс Ит(Жануар):
    анықта дыбыс(өзі) -> мәтін:           # виртуальный метод (переопределение)
        қайтар "Әу!"

үй: тізім[Жануар] = [Ит("Ақбөрі"), Жануар("Х")]
әр ж ішінде үй:
    жаз(ж.аты, ж.дыбыс())
жаз(мысал(үй[0], Ит), түрлендір(үй[0], Ит).аты)    # isinstance и проверяемое приведение вниз
# Жануар.құру(өзі, аты) вызывает метод родителя напрямую (как super)
```

Без `құру` конструктор принимает поля по порядку: `Нүкте(1.0, 2.0)` или `Нүкте(y=2.0, x=1.0)`.
Одиночное наследование. `жоқ` (null) можно присвоить любому классу/списку/словарю/строке/указателю.

### Коллекции

```python
a = [3, 1, 2]
a.қос(5); a.сұрыпта(); жаз(a, a[-1], a[1:3], ұзындық(a))       # [1, 2, 3, 5] 5 [2, 3] 4
d = {"бір": 1}
d["екі"] = 2
әр кілт, мән ішінде d: жаз(кілт, мән)
жаз([x * x әр x ішінде аралық(10) егер x % 2 == 0])             # генератор списка
әр і, x ішінде нөмірле(a): жаз(і, x)                             # enumerate
жаз([1, 2] == [1, 2], (1, "а") == (1, "а"))                      # структурное равенство
```

| `.индекс(x)` `.өшір(i)` `.кірістір(i, x)` `.көшірме()` | | `.бөлу(с)` `.біріктір(список)` | split / join | `.кілттер()` `.мәндер()` |
| `қосынды(l)` `мин(l)` `макс(l)` | | `.тап(с)` `.ауыстыр(a, b)` | найти / заменить | |
| | | `.басталады(п)` `.аяқталады(п)` `.байт(i)` `.байт_саны()` | | |

Множества: `{1, 2, 3}`, `жиын[мәтін]()`, `жиын(список)`, `x ішінде s`, `.қос(x)`, `.жой(x)`, `.тізім()`, операторы `|` `&` `-`.

## Управление памятью

**По умолчанию — автоматическое (GC).** Строки, списки, словари, классы и кортежи живут в куче GC, освобождать ничего не нужно.
GC — консервативный *mark-sweep* (корни: стек и глобальные переменные), память разбита на spans по размерным классам; внутренние указатели понимает.
Объекты без указателей (строки, `тізім[бүтін]` и т. п.) не сканируются.
`жина()` принудительно запускает сборку, `жад()` возвращает размер кучи в байтах.

**Ручное управление** разрешено только внутри блоков `қолмен:`:

```python
қолмен:
    p = бөл(бүтін, 1000)       # *бүтін, обнулён, GC им не управляет
    әр і ішінде аралық(1000):
        p[і] = і * і            # p[i] или *p
    жаз(p[10], *p)
    p2 = p + 5                  # арифметика указателей (с учётом размера элемента)
    босат(p)                    # освободить нужно самому
```

* `бөл(T, n)` выделяет `n` элементов `*T`; для `байт` 1 байт на элемент, иначе 8 байт
* в ручных блоках **можно хранить ссылки на объекты GC** (`бөл(мәтін, 4)`, `бөл(Класс, 4)`): GC считает их корнями
* двойное освобождение или освобождение указателя, полученного не через `бөл`, останавливает программу с ошибкой

## Сеть (TCP, HTTP)

```python
сервер = тыңда_локал(8080)            # слушать только localhost (тыңда(8080) — все интерфейсы)
әзірше рас:
    клиент = қабылда(сервер)          # ждать следующее соединение
    сұраныс = желі_оқы(клиент)        # одно чтение (до 64 КБ), "" если закрыто
    дене = "Сәлем!"
    желі_жаз(клиент, f"HTTP/1.1 200 OK\r\nContent-Length: {дене.байт_саны()}\r\n\r\n{дене}")
    желі_жап(клиент)

с = қосыл("127.0.0.1", 8080)          # клиент; -1 при неудаче (только IPv4 и localhost, DNS нет)
```

Полные примеры: `examples/http_server.tlp`, `examples/http_client.tlp`. HTTPS/TLS и DNS пока нет; один поток (запросы обрабатываются по очереди).

## Многофайловые программы

```python
импорт "утилиталар"        # подключает утилиталар.tlp (путь относительно файла-импортёра), один раз
жаз(квадрат(12))
```

`импорт` вставляет файл на месте (как include): имена общие, код верхнего уровня выполняется там, где стоит импорт.

## Ошибки времени выполнения

Программа завершается с кодом `1`, понятным сообщением и **стеком вызовов (файл, строка, функция)**:
индекс вне границ, нет ключа в словаре, деление на ноль, нулевой указатель (`жоқ`), переполнение стека (1 ГБ виртуального),
сработавший `тексер`, `қате("…")`, `ал` из пустого списка.

```
Шақырулар тізбегі (соңғысы төменде):
  "prog.tlp", 16-жол, <main>
  "prog.tlp", 13-жол, сыртқы
  "prog.tlp", 7-жол, тереңірек
Қате: нөлдік көрсеткішке (жоқ) қатынау
```

(Маленькие встроенные при оптимизации функции могут отображаться под именем вызывающей.)

## Написание ОС

`tulpar os build|run|iso файл.tlp` компилирует программу в **ядро для голого x86-64 железа** (Multiboot: GRUB, `qemu -kernel`, ISO/USB)
вместо Linux-процесса. Весь язык работает в ядре, включая строки, списки, словари, классы и сборщик мусора, а `жаз` печатает в COM1
и на VGA-текст. В блоке `қолмен:` доступны встроенные функции для железа: порты ввода-вывода (`порт_оқы8/16/32`, `порт_жаз8/16/32`),
volatile MMIO (`оқы8..64`, `жаз8..64`), `мекен(T, адрес)` / `мекенжай(p)` для преобразования числа в указатель и обратно,
управляющие регистры и MSR, `cpuid`, `hlt`/`sti`/`cli` и обработчики прерываний на самом Tulpar (`үзіліс_орнату(вектор, функция)`).

```bash
tulpar os run examples/os/shell.tlp        # интерактивная оболочка-ядро в QEMU (COM1 в вашем терминале)
tulpar os iso examples/os/timer.tlp -o os.iso
```

Подробности, полный список функций и ограничения: [docs/os.md](docs/os.md). Нужны `qemu-system-x86_64` (для `run`), binutils, `grub-mkrescue` (для `iso`).

## Структура проекта

```
compiler/src/
  lexer.rs      токены с учётом отступов, f-строки, Unicode-идентификаторы
  parser.rs     парсер рекурсивного спуска -> ast.rs
  check.rs      проверка и вывод типов, AST -> hir.rs (типизированное дерево)
  lower.rs      HIR -> ir.rs (трёхадресный IR с виртуальными регистрами, базовые блоки)
  opt.rs        упрощение CFG, константы, копии, слияние mov, DCE, if-конверсия (cmov)
  inline.rs     инлайнинг маленьких функций
  regalloc.rs   аллокатор регистров linear scan (веса по глубине циклов, callee/caller-saved)
  codegen.rs    x86-64 (синтаксис Intel), System V ABI -> `as` + `ld`
runtime/src/    (no_std, без libc; системные вызовы напрямую)
  gc.rs         память: spans, размерные классы, mark-sweep, ручной аллокатор
  str.rs list.rs dict.rs fmt.rs math.rs misc.rs net.rs sys.rs (+ стек вызовов по таблице строк)
editors/vscode/ подсветка синтаксиса .tlp для VS Code
tools/fuzz.py   дифференциальный фаззер
tests/          *.tlp + *.out (эталон), errors/ (тесты ошибок), run_tests.sh
bench/          бенчмарки (Tulpar / C / Rust / Python)
```

Устройство объектов: строки `[длина в байтах][число символов][байты]`, списки `[длина][ёмкость][данные][флаги]`, классы — поля по 8 байт
(в иерархии нулевое слово — id класса, виртуальные вызовы идут через `vtable[id]`). Все 8-байтные слова сканируются консервативно.

## Производительность

`bench/` (Linux x86-64, 8 ядер). Rust — `rustc -O`, C — `gcc -O2`, Python — CPython 3.14 (`bench/bench.py`). Время одного запуска:

| тест | Tulpar | Rust | C `-O2` | Python 3 |
|---|---|---|---|---|
| Коллатц, 3 млн чисел | 0,59 с | 0,34 с | 0,47 с | 33 с |
| решето Эратосфена, 2·10⁷ | 0,13 с | 0,11 с | 0,10 с | 2,2 с |
| цикл с float, 10⁸ | 0,13 с | 0,12 с | 0,13 с | 18 с |
| `фиб(42)` | 1,55 с | 0,65 с | 0,39 с | 36 с |

Tulpar близок к Rust/C на простых циклах, примерно в 2,4 раза медленнее на рекурсии и в 1,7 раза на ветвистом коде: пока нет раскрутки рекурсии,
векторизации и более умного выбора `cmov`. Оптимизации: инлайнинг, аллокатор регистров linear scan, if-конверсия (`cmov`),
свёртка констант, распространение копий, удаление мёртвого кода, инверсия циклов.

Дифференциальный фаззер (`python3 tools/fuzz.py 0 500`) сравнивает случайные программы в режиме `-O0`, в оптимизированном режиме и с эталоном на Python.

## Ограничения

* Сеть: только TCP/IPv4, нет TLS и DNS, один поток; только Linux x86-64; нужны `as` и `ld` (своего ассемблера/линкера пока нет)
* `импорт` работает как include (пространств имён нет); лямбды не захватывают переменные; нет пользовательских обобщений; нет исключений (`try`)
* Целые 64-битные (длинной арифметики нет, при переполнении «заворачиваются»)
* GC однопоточный и консервативный (ложный указатель изредка может удерживать часть памяти)
* Строки в UTF-8; смена регистра работает для ASCII, кириллицы и казахских букв
